# Storepix roadmap

This roadmap accompanies release 0.5.0. See CHANGELOG.md for released and unreleased work.

## Implemented

- Editable default, minimal, photo, panorama, and feature-graphic templates
- Device presets and localized artwork
- Shared preview/export jobs with screenshot, device, and locale selectors
- Config/asset watch mode with error recovery
- Offline Inter fonts and explicit asynchronous render readiness
- Decoded source validation and opaque, validated PNG exports
- Single-capture panorama slicing and PNG compression
- Bounded workers, sequential mode, and optional local render cache
- Loopback servers, cleanup on failure, and library-safe errors
- Template upgrade backups and generated config types
- Browser integration tests for rendering, reloads, and lifecycle failures

## Next

- Richer annotations (arrows, highlights, callouts)
- Additional landscape-specific template layouts
- RTL-specific layout coverage and bundled font options for more scripts
- Visual regression baselines for a larger device/template matrix
- Store upload workflow examples and Fastlane integration guide
- Documentation site with a community example gallery
- Accessibility contrast checks and automatic text fitting

`plain` and `split` are not currently bundled templates.
